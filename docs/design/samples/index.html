ReNovel デザイン案

4案を用意しました。カードをクリックすると単体で開きます。好みのものを選んでください。

案A — 文芸セリフ

開く →

明朝体・紙のような温かい配色・余白多め。Text First を最も体現した落ち着いた文芸系。

案B — モダンミニマル

開く →

白基調・ゴシック・teal アクセント（Kiwa UI の primary 準拠）。プロダクト然としたクリーンで今風の印象。

案C — ダークフォーカス

開く →

暗色・高コントラスト・cyan。夜の読書向け。リアルタイム読者数などデータ表示が映える。

案D — エディトリアル

開く →

明朝ディスプレイ・誌面レイアウト・バーミリオン。特集を大きく見せる、雑誌のような存在感。

※ これらは選定用のスタンドアロン HTML モック（Tailwind Play CDN 使用）。採用後、実装は Kiwa UI + Tailwind v4 で app/src に起こします。共通要素：表紙画像なし・ルビ/傍点表示・作品一覧・ランキング・読書プレビュー。
